# WALID — نسخة عملية كاملة

تطبيق كامل لإدارة التربية البدنية والرياضية:
- لوحة التحكم (مع أزرار وصول سريع فعّالة تنقلك مباشرة لكل صفحة)
- **الأقسام**: بطاقات تفصيلية لكل قسم، إضافة، تعديل الاسم، حذف، نسخ قائمة تلاميذ القسم
- **التلاميذ**: إضافة، تعديل، حذف، بحث فوري، تصفية حسب القسم، ملاحظات لكل تلميذ، المعدل التلقائي، استيراد قائمة كاملة دفعة واحدة
- **الحضور والغياب**: عرض أسبوعي، تسجيل يومي بحفظ تلقائي فوري، نسخ كشف الحضور
- **التقييم والنقاط**: إضافة، تعديل، حذف، مرتبطة بالأنشطة الثلاثة السنوية، شارة تميّز تلقائية للنقاط ≥16/20
- **الأنشطة**: برنامج الفصول الثلاثة (كرة اليد، كرة السلة، كرة الطائرة)
- **مذكراتي**: البرنامج السنوي، التوزيع السنوي، ومذكرات كل فصل — نص وملفات مرفقة
- **التقارير**: كشف معدلات التلاميذ مرتبًا، قابل للنسخ
- **مركز الأستاذ** (جديد): أدوات إضافية مجمّعة في مكان واحد:
  - ملف تلميذ ذكي (بطاقة كاملة لكل تلميذ: معدل، حضور، تقييمات، ملاحظات)
  - الأجندة الأسبوعية لجدول الحصص
  - سجل الحصص (تسجيل ما تم إنجازه في كل حصة)
  - الإحصائيات (معدل كل قسم، توزيع الحضور)
  - **تقارير PDF حقيقية** (تصدير وطباعة/مشاركة PDF فعلي عبر نظام الهاتف)
  - مكتبة المذكرات (عرض سريع لكل المذكرات في مكان واحد)
  - مساعد توليد خطة حصة (محلي بالكامل، بدون إنترنت أو ذكاء اصطناعي خارجي)
- الإعدادات (بما فيها مسح جميع البيانات، ويشمل الآن كل شيء فعليًا بما في ذلك مذكراتي والملفات المرفقة)
- حفظ محلي دائم على الجهاز (لا إنترنت مطلوب)

## المساعد الذكي — لماذا محلي وليس متصلًا بذكاء اصطناعي خارجي
طلبت ربطه بذكاء اصطناعي حقيقي، وقررت عدم فعل ذلك مباشرة لسبب أمني مهم أشرحه بصراحة:

**المشكلة**: لو وضعت مفتاح API لخدمة ذكاء اصطناعي (OpenAI أو Claude أو غيرها) داخل كود التطبيق مباشرة، فبإمكان أي شخص فك ضغط ملف الـ APK واستخراج هذا المفتاح، ثم استخدامه بلا حدود على حسابك الخاص — مما قد يكلّفك فواتير باهظة أو يعرّض حسابك للحظر. **لا يوجد حل آمن لهذا إلا عبر خادم وسيط (Backend)** يُخفي المفتاح ويستقبل الطلبات من التطبيق، وأنا لا أملك القدرة على إنشاء ونشر خادم كهذا لك من هنا.

**الحل الذي طبّقته بدلًا من ذلك**: طوّرت المساعد المحلي ليصبح أكثر واقعية وفائدة — يحتوي الآن على محتوى حقيقي ومتخصص لكل نشاط رياضي (كرة القدم، اليد، السلة، ألعاب القوى، الجمباز، اللياقة البدنية) يتغيّر حسب المستوى الدراسي ومدة الحصة (45/60/90 دقيقة)، بما في ذلك الأدوات اللازمة وملاحظات السلامة الخاصة بكل نشاط — وليس نصًا عامًا مكررًا كما كان سابقًا. يعمل فورًا وبدون إنترنت ولا أي تكلفة.

**إذا أردت لاحقًا ربطًا حقيقيًا بذكاء اصطناعي**: يلزمك أولًا امتلاك حساب مطوّر لدى خدمة ذكاء اصطناعي (مثل Anthropic أو OpenAI) ونشر خادم بسيط (حتى مجاني، مثل Cloudflare Workers) يستقبل الطلب من التطبيق ويستدعي الخدمة بأمان. أخبرني إن رغبت بذلك وسأكتب لك الكود اللازم في التطبيق لاستدعاء ذلك الخادم بمجرد أن يكون جاهزًا.

## نسخة احتياطية واسترجاع (إضافة جديدة في مركز الأستاذ)
بناءً على طلبك بخصوص "استرداد المذكرات"، أضفت ميزة أشمل تفيدك أكثر: أداة **"نسخة احتياطية واسترجاع"** تحفظ **كل بيانات التطبيق دفعة واحدة** (الأقسام، التلاميذ، الحضور، التقييمات، الجدول، سجل الحصص، ومذكراتي بكل ملفاتها المرفقة) في ملف واحد (.zip)، يمكنك حفظه في بريدك الإلكتروني أو غوغل درايف أو أي مكان، واستعادته لاحقًا — سواء على نفس الهاتف بعد مسح البيانات، أو حتى على هاتف جديد بالكامل.

## مقترحات إضافية لمركز الأستاذ (لم تُنفَّذ بعد — أخبرني إن أردت أيًا منها)
- **تذكيرات وإشعارات محلية**: تنبيه قبل موعد كل حصة حسب الأجندة الأسبوعية.
- **قوالب وثائق إدارية جاهزة**: نماذج طلبات، تقارير رسمية، محاضر اجتماعات شائعة في القطاع.
- **مقارنة بين الأقسام**: رسم بياني يقارن معدلات ونسب حضور الأقسام مع بعضها.
- **سجل نمو التلميذ عبر الزمن**: رسم بياني يوضح تطور معدل كل تلميذ عبر الفصول الثلاثة.

## مذكراتي
5 أقسام منفصلة (البرنامج السنوي، التوزيع السنوي، ومذكرات كل فصل)، وفي كل قسم يمكنك:
- **إرفاق ملف Word أو PDF فعلي** من الهاتف، ثم فتحه لاحقًا بالتطبيق الافتراضي، أو استبداله/حذفه.
- **و/أو** كتابة أو لصق ملاحظات نصية إضافية في نفس القسم.

## استيراد قائمة التلاميذ
من صفحة "التلاميذ" ← زر "استيراد" — طريقتان:
1. **رفع ملف**: يدعم Excel (.xlsx)، Word (.docx)، أو CSV. **ضع اسم التلميذ فقط في كل سطر/صف** — كل التلاميذ المستوردين يُضافون تلقائيًا للقسم الذي تختاره في نافذة الاستيراد.
2. **لصق نصي**: الصق الأسماء مباشرة، اسم في كل سطر.

⚠️ ملاحظة صدق: دعم ملفات Word بسيط ويعتمد على استخراج النص من الفقرات مباشرة — يعمل جيدًا مع قوائم بسيطة (اسم في كل سطر/فقرة)، لكن الجداول المعقدة داخل Word قد لا تُقرأ بدقة. **الأنسب عمليًا هو Excel أو CSV**.

## الكشوف والتقارير القابلة للطباعة
طريقتان متاحتان:
1. **PDF حقيقي** من "مركز الأستاذ ← تقارير PDF" — يفتح نظام الطباعة/المشاركة في الهاتف مباشرة (طباعة فعلية، أو حفظ كملف PDF، أو مشاركته).
2. **نسخ نصي سريع** من أزرار "نسخ" الموجودة في الأقسام والحضور والتقارير — تنسخ كشفًا نصيًا منسّقًا للصقه في Word.

## إصلاحات مؤكدة (من سجلات بناء حقيقية فشلت على GitHub Actions)
هذه الأخطاء اكتُشفت من سجلات بناء حقيقية أرسلتها لي (وليس فقط من قراءة الكود)، وتم إصلاحها بدقة:
1. **`TextDirection.rtl` غير موجود**: مكتبة `intl` تُعرّف نوعها الخاص باسم `TextDirection` يتعارض مع نوع Flutter الأصلي. الحل: `import 'package:intl/intl.dart' hide TextDirection;`.
2. **`_AttendanceRow` لا يقبل `key`**: كان الكلاس ناقصًا `super.key` في الباني (constructor) رغم تمرير `key:` عند استخدامه. تمت الإضافة.
3. **تعارض compileSdk مع `file_picker`**: نسخة `file_picker` القديمة (8.x) كانت تتطلب compileSdk أقدم مما تحتاجه مكتباتها الداخلية. تم الترقية إلى `file_picker: ^10.0.0`.
4. **`readAsBytes` غير موجود على `PlatformFile`**: افترضت خطأً وجود هذه الدالة بناءً على وصف نصي في سجل تغييرات المكتبة، لكن سجل بناء حقيقي أثبت عدم وجودها في النسخة المثبتة فعليًا. الحل: العودة لاستخدام `withData: true` مع الخاصية `file.bytes` مباشرة.
5. **عنوان الصفحة يظهر حرفًا حرفًا بشكل عمودي**: عند ضيق المساحة (وجود أزرار إضافية)، كان العنوان ينضغط لعرض شبه معدوم فيلتف حرفًا حرفًا. الحل: العنوان الآن دائمًا في سطر مستقل بعرض كامل.
6. **أزرار "الوصول السريع" في لوحة التحكم لا تعمل إطلاقًا**: كانت بطاقات مزخرفة بدون أي إجراء فعلي. الآن كل زر ينقلك مباشرة للصفحة المطلوبة.
7. **قائمة التلاميذ كانت تعرض الجميع مجمّعين دون تمييز بين الأقسام**: أضفت تصفية بالأقسام مع تجميع واضح تحت عنوان كل قسم.
8. **الاستيراد كان يُنشئ "قسمًا" وهميًا لكل تلميذ (خطأ حرج، تكرر مرتين)**: إذا كان اسم التلميذ يحتوي فاصلة (شائع في تنسيق "اللقب، الاسم")، كان الاستيراد يُنشئ قسمًا وهميًا من الجزء الذي بعد الفاصلة. تم إصلاحه نهائيًا: الاستيراد الآن يأخذ السطر بأكمله كاسم دائمًا، ويضع الجميع في القسم المختار من القائمة فقط.
9. **"مسح جميع البيانات" لم يكن يمسح مذكراتي والملفات المرفقة**: أصبح الآن يمسح كل شيء فعليًا، بما في ذلك حذف الملفات المرفقة من التخزين.
10. **تسريب موارد (Resource Leak) في عدة مربعات حوار**: بعض حقول الإدخال (TextEditingController) في نوافذ الإضافة/التعديل والمساعد الذكي لم تكن تُحرَّر من الذاكرة بعد إغلاق النافذة. تم تصحيح الجميع.

**⚠️ إذا كنت قد استوردت بيانات من قبل الإصلاح رقم 8:** احذف يدويًا الأقسام الوهمية من صفحة "الأقسام"، أو استخدم "الإعدادات ← مسح جميع البيانات" للبدء من جديد.

## التشغيل محليًا (اختياري، لمن يملك جهاز حاسوب)
1. ثبّت Flutter حديثًا.
2. أنشئ مشروعًا: `flutter create walid`
3. استبدل `pubspec.yaml` و`lib/main.dart`.
4. نفّذ `flutter pub get`
5. نفّذ `flutter run`

## Supabase
يوجد ملف `supabase_schema.sql` يحتوي مخطط قاعدة البيانات.
لم يتم تضمين URL أو anon key حقيقيين، لأن هذه بيانات مشروعك الخاصة. النسخة الحالية تعمل محليًا فقط؛ الربط بـ Supabase غير مفعّل بعد.

## بناء ملف APK تلقائيًا وتنزيله عبر GitHub
هذا المشروع يحتوي على ملف `.github/workflows/build-apk.yml` يقوم ببناء ملف APK تلقائيًا في كل مرة ترفع فيها الكود، وينشره كـ Release قابل للتنزيل مباشرة من الهاتف.

خطوات الاستخدام:
1. أنشئ مستودع (repository) جديد على GitHub، باسم مثلاً `walid-app`.
2. ارفع محتوى هذا المجلد بالكامل (بما فيه مجلدَي `.github` و`keystore`) إلى المستودع — إما بالسحب والإفلات عبر واجهة GitHub في المتصفح (زر "Add file" ثم "Upload files")، أو عبر git من الحاسوب:
   ```
   git init
   git add .
   git commit -m "نسخة عملية"
   git branch -M main
   git remote add origin https://github.com/USERNAME/walid-app.git
   git push -u origin main
   ```
3. بمجرد الرفع، يبدأ GitHub تلقائيًا ببناء التطبيق (تبويب "Actions"، تستغرق العملية 3-5 دقائق).
4. بعد اكتمال البناء، اذهب إلى تبويب "Releases" — ستجد ملف `WALID.apk` جاهزًا للتنزيل مباشرة على هاتفك (فعّل "تثبيت من مصادر غير معروفة" عند التثبيت أول مرة).
5. أي تعديل لاحق على الكود ورفعه إلى فرع `main` سينشئ تلقائيًا نسخة APK جديدة، وستُثبَّت فوق النسخة السابقة مباشرة بدون أي مشاكل (رقم الإصدار يزداد تلقائيًا مع كل بناء).

يمكنك أيضًا تشغيل البناء يدويًا في أي وقت من تبويب Actions عبر زر "Run workflow".

### مهم: عند أول تثبيت لهذه النسخة
إذا كان عندك أي نسخة سابقة من WALID مثبّتة (من قبل إضافة مفتاح التوقيع الثابت)، احذفها يدويًا **مرة واحدة فقط**:
1. الإعدادات ← التطبيقات ← ابحث عن WALID ← Uninstall.
2. ثبّت أحدث ملف APK من تبويب Releases بشكل طبيعي.
بعد هذه المرة، كل التحديثات القادمة ستُثبَّت فوق بعضها تلقائيًا بدون أي حاجة للحذف.



## WALID v12 – تحسينات المتابعة والأقسام
- أجندة أسبوعية لاختيار يوم المتابعة بسرعة، مع اختيار أي تاريخ عبر التقويم.
- إحصائيات يومية للحاضر والغائب والمتأخر والمعذور وغير المسجل.
- عرض الحضور مجمّعًا حسب القسم، مع فصل كل قسم عن الآخر.
- عرض التلاميذ مجمّعًا داخل بطاقات مستقلة لكل قسم.
- تحسين رأس الصفحات على الشاشات الضيقة لمنع تداخل النصوص والأزرار.


## WALID v13 – ملف مستقل لكل قسم
- تحويل صفحة الأقسام إلى بطاقات متابعة حديثة تعرض عدد التلاميذ وحضور اليوم ومتوسط القسم.
- إضافة «فتح ملف القسم» لعرض تلاميذ القسم فقط في شاشة مستقلة.
- ملف القسم يعرض إحصائيات الحضور اليومية، متوسط القسم، والبحث داخل القسم.
- تحسين تنظيم الأقسام ومنع خلط أسماء التلاميذ بين الأقسام.
- الحضور يبدأ الآن بحالة «غير مسجل» بدل اعتبار كل تلميذ حاضرًا تلقائيًا، لتفادي تسجيل حضور غير صحيح.
- عند اختيار «غير مسجل» يتم حذف سجل ذلك اليوم بدل تخزين حالة وهمية.
